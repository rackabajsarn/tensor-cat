About CatCam

Image Collection

Images are captured by an ESP32-CAM at the cat flap and sent via MQTT to this server. New images appear in the main gallery for classification.

Labeling System

Each image can be classified with four binary labels:

  • Cat – A cat is visible in the image
  • Morris – The cat is Morris (our cat)
  • Entering – The cat is entering (vs leaving)
  • Prey – The cat is carrying prey

Labels are stored directly in the image's EXIF metadata, so they travel with the file.

Image Workflow

  • Incoming: static/images/ – New images from the camera
  • Dataset: dataset/images/ – Classified images used for training

Once you save labels on an image, it moves to the dataset. You can reclassify images from the gallery at any time.

Live Accuracy

Each inference stores a compact hash plus both ESP and server predictions in SQLite. When you label gallery images, the true label is linked back to that hash, enabling an accumulated (real-world) accuracy metric that works for both 2-class and 3-class models.

  • Training accuracy: Reported from the training run (metrics.json).
  • Accumulated accuracy: Computed from logged inferences with true labels, shown in the model list, active model summary, and reports (with a live confusion matrix).

Model Training

Two models can be trained from the labeled dataset:

  • Server Model: Transfer learning on EfficientNet for Coral TPU – runs on the server for high-accuracy classification
  • Local Model: Lightweight CNN for ESP32 – runs on the camera itself for real-time prey detection

Model Versioning

Each training run is saved as a versioned snapshot with:

  • Model files (.tflite, .keras, .cc/.h for ESP32)
  • Classification reports and confusion matrices
  • Accuracy metrics for quick comparison

You can switch between versions at any time, compare performance, and delete old versions you no longer need.

Tech Stack

  • Backend: Flask (Python)
  • ML Framework: TensorFlow / Keras
  • Edge Inference: TensorFlow Lite (Coral TPU & ESP32)
  • Communication: MQTT for image transfer
  • Hardware: ESP32-CAM, Google Coral USB Accelerator
