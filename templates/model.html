Server Parameters

  • Epochs — passes on the frozen base. More can improve fit until validation loss stops dropping; too many may overfit.
  • Fine-tune Epochs — extra passes after unfreezing. Keep modest to avoid destroying pretrained features; extend only if validation keeps improving.
  • Learning Rate — optimizer step size. Higher = faster progress but can spike loss; lower = steadier, slower. If loss oscillates, lower this.
  • Unfreeze From Layer — layer index where fine-tuning begins. Higher index freezes more of the backbone (safer, less compute); lower index retrains more layers (potentially better accuracy, higher overfit risk).

Local Parameters

  • Epochs — total passes. Increase until validation loss plateaus; excessive values overfit and waste time.
  • Validation Split — percent held out for validation. More split = better feedback but fewer training samples.
  • Learning Rate — step size. Too high = unstable loss; too low = slow progress. Nudge down if loss spikes.
  • Batch Size — images per step. Larger is smoother/faster on CPU but can generalize slightly worse; smaller is noisier but sometimes better.
  • Classes — 2-class (prey/not_prey) vs 3-class (adds not_cat). Changing this resets labels and metrics to the new outputs.
  • Max Samples Per Class — cap per class for speed/balance. 0 = use all; lower caps shorten training but may drop rare edge cases.
  • Seed — fixes shuffling/splits for reproducible results.
  • Early Stop Patience — epochs to wait for val loss to improve. Lower stops earlier (less overfit), higher allows longer climbs.
  • Weight Decay — L2 regularization on weights. Small values reduce overfitting; large values can underfit.
  • Dropout — fraction of features dropped before the head. Higher adds regularization; too high hurts accuracy. No effect at inference time.
  • Augmentation — off/light/medium image perturbations. More aug improves robustness but can slow convergence if labels are noisy.
  • Class Weights — rebalances loss toward rare classes. Turn on when one class dominates; turn off if classes are already balanced.
  • Label Smoothing — softens targets to curb overconfidence. Use small values (≤0.1); too much degrades accuracy.
  • LR Schedule — constant (steady), cosine (smooth decay), or step (sharp drops mid-training). Decay usually helps late-epoch stability.
  • Warmup Epochs — slowly ramp the LR at the start. Useful when using higher LRs or heavy augmentation; 1–3 is typical.
